# AC Tel Örgü · Çit Planlayıcı

Satışçılar için 3D çit planlama ve teklif uygulaması.

## 👉 [Uygulamayı tarayıcıda aç](https://hakanaydemir20.github.io/ac-tel-orgu-planlayici/)

**https://hakanaydemir20.github.io/ac-tel-orgu-planlayici/**

## Neler yapar

- Araziyi hazır şekillerden seçme ya da elle çizme, kenar ölçüleri ve eğim
- Tel (kafes, panel, dikenli, tavuk teli), direk (beton, profil, boru), kaş, payanda, kapı ve üst tel seçimi
- Canlı 3D görünüm, görünüm küpü, köşe yakın çekimi
- Soru-cevap ile adım adım planlama
- Malzeme listesi, fiyat ve KDV hesabı; göz aralığı ve tel kalınlığına göre kafes tel fiyatı
- Tek sayfa A4 PDF teklif, yazdırma ve WhatsApp ile gönderme
- Teklif arşivi (fiyatlar teklif tarihindeki haliyle kalır)
- Ayarlar ekranından satış fiyatları ve firma bilgileri
- Koyu ve açık tema

Veriler (fiyatlar, teklifler) kullanılan tarayıcıda saklanır.

## Geliştirme

```bash
npm install
npm run dev      # http://localhost:3000
npm test
```

`main` dalına her gönderimde GitHub Actions uygulamayı derleyip GitHub Pages'e yayınlar.
